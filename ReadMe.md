# Info
Perfect for swfs that don't know map callouts yet, simply use it as an overlay while playing.

# Features:

* Choose a map
> A dropdown that let's you type & Choose a map

* Map Display
> Displays the map you chose on the GUI

* View Map
> Creates a Pop Out Overlay of the selected Map

* Top Most
> Displays the Overlay above other applications (like dbd)

* Clickthroughable
> You can click through the overlay so you don't accidentally move it mid game. (disable this setting to drag the window to a different position)

* Prevent Map NoClip
> Prevents you from dragging the map out of your monitors screen size (prob doesn't work that well)

* Image Size X
> Set the image size on the x axis

* Image Size Y
> Set the image size on the y axis

* Reset Window Size
> Resets the Overlay Size
